# Tutorial video registry

Tutorial buttons use `tutorialVideoRegistry.ts` as the explicit feature-to-video
source of truth. A `undefined` URL is intentional: the corresponding button is
hidden until the founder supplies a link. Feature-keyed buttons never inherit a
generic video.

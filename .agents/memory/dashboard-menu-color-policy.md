name: Dashboard menu color distinction
description: User wants dashboard tools visually distinguished by different accent colors, not merely different shades of the same hue.
---

Dashboard menu cards should have visually distinct accent colors rather than repeating the same color for unrelated tools.

**Why:** The user disliked Macro Calculator resembling Daily Journal/Inspiration and Recipe Maker resembling Saved Meals, and said, "I would like all of these menus to be different colors."

**How to apply:** Compare proposed accents against neighboring cards, including their dark translucent glows, not just exact hex values. Keep unread-message indicators visually distinct from a message card's normal accent. Do not recolor additional cards beyond the approved scope.

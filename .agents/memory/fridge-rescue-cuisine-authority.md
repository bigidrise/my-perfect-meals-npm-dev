name: Fridge Rescue cuisine authority
description: Governs selected cuisine, ingredient-control behavior, and repair ordering in Fridge Rescue.
---

An explicitly selected Fridge Rescue cuisine is authoritative creative direction for every returned candidate, not a soft ranking preference. Normal ingredient control may add bounded pantry support needed for cultural identity; Keep It Simple may not.

**Why:** Prompt-only cuisine instructions can still return a mixed set, especially when ingredient restrictions conflict with cuisine-defining flavors. Relabeling a generic dish is not compliance.

**How to apply:** Validate each candidate's culinary identity, preserve compliant meals, and repair only failures. Any repaired meal must then pass the existing dietary, allergy, clinical, GLP-1, and Human Food validation stack before release.

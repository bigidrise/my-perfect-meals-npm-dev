---
name: Studio message composer controls
description: Approved visual and capability boundaries for Studio messaging controls.
---

Client Folder messaging and the client's Client Messages composer must use the same basic control order and colors: primary purple Send, orange Voice, and prominent red Video.

**Why:** The user confirmed that the normal pre-recording camera action should be highly discoverable; the dedicated recording interface provides the distinct active-recording state after it is pressed.

**How to apply:** Keep the normal Video action red with a visible camera icon and an accessible label. Do not add voice or video to Provider Messages unless that separate capability is explicitly approved.
